# Mausam Mitra AI

Mausam Mitra is an AI-powered conversational weather assistant.

## Features

- Gemini-based user intent understanding
- Persona detection
- Language detection
- Location and date extraction
- Capability checking
- Conversational service navigation
- Open-Meteo weather integration
- Relevant forecast selection
- Hindi, Hinglish and English responses
- TTS-friendly response generation

## Architecture

User Query
↓
Gemini Understanding
↓
Intent / Persona / Location / Date
↓
Capability Check
↓
Service Navigation
↓
Open-Meteo
↓
Relevant Weather Data
↓
Gemini Response Generation
↓
Final User Response
